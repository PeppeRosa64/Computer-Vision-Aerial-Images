This repository contains a collection of three distinct Computer Vision projects focused on the analysis, geometric alignment, and classification of aerial and satellite imagery.

Developed as part of an advanced university course, this suite demonstrates a progressive application of computer vision techniques, evolving from foundational mathematical models to modern Deep Learning architectures.

Repository Structure:
1. Multimodal Image Registration: Alignment of RGB and Thermal image pairs by estimating optimal geometric transformations through the maximization of Mutual Information.

2. Bag-of-Visual-Words Classification: A traditional Machine Learning pipeline extracting local descriptors (SIFT/ORB) to build a visual vocabulary (K-Means) and classify land-use categories using shallow classifiers (SVM, Random Forest).

3. Residual CNN Classification: A Deep Learning approach featuring a custom-built Convolutional Neural Network with residual blocks, comparing from-scratch training against Transfer Learning (pre-training and fine-tuning) strategies.

Navigate to the individual folders for detailed documentation, source code, and inference scripts for each project.
